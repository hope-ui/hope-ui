# `MESSAGES_SV` — Swedish catalog

Built-in **Swedish** catalog, selected when the active locale's primary subtag is `sv`. Shape + key
list: `../messages.md`. Selection + fallback: `catalogs.md`.

- Both count-bearing nouns — *datum* and *alternativ* — are neuter and invariant across number, so
  each key inflects only the participle/adjective: `1 datum valt` / `2 datum valda`,
  `1 alternativ tillgängligt` / `2 alternativ tillgängliga` (neuter singular, then plural).
