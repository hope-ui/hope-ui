# `MESSAGES_DA` — Danish catalog

Built-in **Danish** catalog, selected when the active locale's primary subtag is `da`. Shape + key
list: `../messages.md`. Selection + fallback: `catalogs.md`.

- Both count-bearing keys: singular only at `1` — `1 dato valgt` / `2 datoer valgt`,
  `1 mulighed tilgængelig` / `2 muligheder tilgængelige` (the adjective *tilgængelig* agrees; the
  participle *valgt* does not).
